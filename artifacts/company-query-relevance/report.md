# Gate 1: «Компании» и «Запросы и релевантность»

## Что сделано

- В раскрывашку «Компании · N» подключён фильтр из первой реализации: поиск по имени, домену и связанным запросам; сегменты реальных типов; сортировка по компании и числу найденных запросов; доля `K из M`, полоса, раскрытие запросов и «Топ-5» при убывании числа связей. Простой список сохранён в коде как неиспользуемый исторический рендерер.
- Отдельная раскрывашка «Запросы и релевантность · M» показывает запросы, реальные оценки и «Не оценена», число найденных компаний и распределение по типам. Поиск, сортировка, раскрытие и сброс работают на клиенте.
- Оба вида используют отдельные JS/CSS, существующие токены приложения и состояние экрана. Основной `gate1-company-analysis.js` содержит точки подключения и сохранения раскрытого состояния при перерисовке. Поиск перерисовывает строки, сохраняя узел поля и фокус.
- Обработчики ввода и изменения полей поиска перехватывают события до общего обработчика карточки, который иначе вызывал инициализацию данных проекта. Проверка с запретом `g1CompanyComparisonEntry(true)` прошла.

## Проверки

`npm run build` прошёл: `2.3.526+cb35bb6d6ed5`, 49 файлов сборки совпали.

Прошли `gate1-company-query-relevance-smoke.mjs` на четырёх проектах, `gate1-company-search-guide-smoke.mjs`, `gate1-company-analysis-smoke.mjs`, `gate1-company-analysis-projects-smoke.mjs` и отдельный запуск `gate1-comparison-performance-smoke.mjs`. При одновременном запуске нескольких тяжёлых браузерных смоуков проверка производительности один раз превысила порог (1137 мс); отдельный повтор прошёл (18 мс). Профильный `gate1-company-keyword-filter-smoke.mjs` проверен отдельно.

Сравнивался `JSON.stringify(state)` целиком, включая временные поля, до и после поиска, сегментов, сортировки, раскрытия и переходов к запросу из обеих раскрывашек. Полный файл экспорта большого проекта не создавался. Хеши сериализованного состояния до и после совпали:

Старый `gate1-company-keyword-relevance-smoke.mjs` проверяет отменённый фильтр релевантности внутри списка компаний, поэтому для текущего задания его заменяет `gate1-company-query-relevance-smoke.mjs`.
