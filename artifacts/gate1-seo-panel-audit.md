# Gate 1 · SEO — аудит live-источников

Сборка: `2.3.147`  
Модуль: `gate1-seo-panel.js`  
Режим: только чтение, отдельное хранилище SEO-панели не создано.

## Точка рендера

Панель добавляется в Gate 1 внутри существующей оболочки
`data-guru-product-context="gate1-product-pages"`, сразу после общего
селектора «Категория → Товар». Селектор не копируется: продуктовый срез
читает текущее значение `guruV194Ui` через `guruV194SelectedProduct`.

Визуально переиспользованы:

- `guru-strategic-row-v286` и его status/source meta из «Стратегической основы»;
- `guruStrategicKeywordCardV249` для трёх компактных уровней Фундамента;
- стандартные `g1-section`, `passport-v116-input` и `status-pill`.

## Компания

| Пункт панели | Live-источник | Статус/сводка | Переход |
| --- | --- | --- | --- |
| Аудит сайта | `getGate1Sections(...).site_audit.allInnerCards` | `getSectionStatus`, фактическое `ready/total` без захардкоженного количества | раскрывает `site_audit` |
| Яндекс Вебмастер | `state.gate1WebmasterV295.company` | четыре независимых resolver’а: подтверждение, Sitemap, Robots, ошибки | к блоку «Яндекс Вебмастер · Компания» |
| Канонический URL и редиректы | существующая карточка `Канонический URL и редиректы` | `redirectV130CardStatus` применяется к клону карточки; URL и заполненные проверки читаются из `redirectV130` | к исходной карточке Gate 1 |
| Сравнение проектов | `state.projectComparison` | `projectComparisonStatus(model)` | к существующему блоку сравнения |

«Сравнение проектов» физически является существующим блоком Gate 1.
Поэтому подпись намеренно честная: `← Gate 1 · Сравнение проектов
(данные Gate 0–1)`. Собственные значения проекта внутри карты уже читаются
из Gate 0–1, но сама карта конкурентов не хранится в Gate 0.

## Продукт

| Пункт панели | Live-источник | Привязка |
| --- | --- | --- |
| Фундамент · исходный | `guruV247KeywordFoundationStats(product, state)` | `product_id`, Gate 0 |
| Фундамент · середина | `guruGate1MiddleStatsV257(rowClone)` | строка Карточки товара с тем же `catalogItemIdV189` |
| Фундамент · Финальный | `guruStrategicFinalEntriesV286(guruGate1FinalPainContextV259(product, false)?.itemData)` | `product_id`, Gate 1 Финальный |
| SEO-сниппет товара | `row.title`, `row.description`, `row.contextFields.seoKeywords` | строка выбранного товара |
| Яндекс Вебмастер · индексация | `gate1WebmasterProductV295(product.id, state, false)` | точный `product_id` |

Если продукта или источника нет, пункт остаётся видимым со статусом
«Не начато». Ничего не пропускается молча.

## Хранение и обновление

- Не создано `state.gate1Seo`, `state.project.seoPanel` или аналогичных ключей.
- Не добавлены migration/prepare/create hooks.
- У панели нет собственных полей ввода и обработчиков сохранения.
- На `input/change` исходного блока заменяется только DOM-проекция панели;
  значения повторно читаются из существующего источника.
- Существующие блоки, поля, статусы и места редактирования не изменены.
