# Gate 4 · SMM-контент-система · audit v2.3.99

## READ · безопасные источники

Новая система хранится только в `workspace.gate4SmmContentV299`. Для материала идеи используются прямые read-only чтения без `ensure`, миграций и создания полей в исходных гейтах:

| Материал | Фактический источник | Режим |
|---|---|---|
| JTBD, Сегмент, Позиционирование, УТП, Оффер | `project.gate0ScopedValuesV194`, product → category → project | live read-only |
| «Как создаётся» | строка выбранного товара в карточке товара Gate 1, `contextFields.productCreationV253` | live read-only |
| Подтверждённые финальные фразы | `painV130.productMaps[].items[product_id].demandRows[]` с `finalFoundationImportedAtV259` | live read-only |
| Форматы, темы и пороги | `gate4SmmStrategyV298` | live read-only внутри идеи; редактирование остаётся только в SMM-стратегии Gate 4 |

Публичная модель панели «Стратегическая основа» не вызывается из карточки идеи: её текущая ветка может нормализовать дополнительные JTBD через `ensure`. Для жёсткой гарантии нулевых записей в Gate 0–3 повторена только её иерархия разрешения источников в чистых read-only функциях.

## WRITE · реализовано только в Gate 4 / Aware

- Список карточек идей с выбором «бренд в целом» или `product_id`.
- Все пять стадий Джеймса Уэбба Янга видны одновременно; текущая стадия является состоянием карточки, но не блокирует остальные.
- Стадия 1 показывает живые данные товара и справочник SMM-стратегии; стадии 2–4 сохраняют заметки, инкубацию и формулировку идеи.
- «Оформить как публикацию» идемпотентно создаёт одну карточку публикации и переносит снимок контекста, идею и заметки.
- Публикация хранит тему, формат, площадки, дату, ссылку, статус, заголовок, описание, содержимое и шесть фактических метрик.
- Выбор формата подставляет площадки; мультивыбор остаётся редактируемым. Несколько площадок не создают несколько карточек.
- Для каждой метрики считается отношение к среднему по опубликованным карточкам того же формата за последние 90 дней. До трёх карточек истории выводится «Недостаточно данных для сравнения».
- Сводка «Что нужно сделать» показывает недельный и квартальный объём, неиспользованные пары формат × площадка за 90 дней и темы без публикаций более трёх недель.
