# Gate 0: единый источник готовности, шаг 2.1

## Изменение расчёта

Значок на странице, путь, подсказки и процент Gate 0 получают одну оценку `guruGate0BlockReadiness`. Оценка работает через существующий защищённый режим чтения. Ввод обновляет три поверхности в одном цикле без перестройки формы.

Сохранённые статусы скрытых объединённых карточек исключены из оценки. Их записи и значения сохранены. Отдельных полей, хранилищ и миграций не добавлено.

Для продуктового блока учитывается выбранный `product_id`. Ранее значок блока проверял все продукты, а путь выбранный продукт и скрытые статусы. Теперь используются видимые редакторы выбранного продукта: JTBD читает общие определения своих трёх полей, офферы используют существующую проверку трёх линз и основного CTA, единая формулировка читается из существующего `value`. Для остальных разделов сохранена проверка существующих значений. Унаследованные значения читаются с тем же приоритетом продукт, категория, проект, что и на странице; скрытые структурированные поля предпросмотра не создают требований. «3 из 4» означает лимит записей JTBD, а не обязательную четвёртую запись.
