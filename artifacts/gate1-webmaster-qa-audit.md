## READ

До изменения общий `megaMarketing.infra[Яндекс Вебмастер]` напрямую читал
только `card-107` («подтверждение сайта»). `card-108` и `card-109` читали
старые самостоятельные карточки Gate 1 `Sitemap.xml` и `Robots.txt` из
«Аудита сайта». У `card-110` и `card-111` отдельного точного источника не
было.

Кроме известных карточек Gate 2, строку Gate 0 читали:

- рендер инфраструктуры `megaInfraSectionHtml`;
- общий статус megaMarketing-карточки через `megaMarketingStatus`;
- готовность инфраструктуры привлечения в Gate 3 через
  `g3ActionStages → g3InfraRows(/вебмастер/)`;
- runtime-модель экспорта и диагностики `guruExportRuntimeModelV223`.

Статические инструкции и ссылки на сервис «Яндекс Вебмастер» состояния
этой строки не читают и не переподключались.

`card-167` уже является продуктовой карточкой `readinessV225`. Рабочие поля
её строк сохраняются по стабильному адресу
`product_id → card-167 → row_key`, поэтому отдельное хранилище для цели
Метрики не создавалось.
