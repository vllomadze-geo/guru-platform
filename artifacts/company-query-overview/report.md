# «Запросы и релевантность»: отчёт

## Изменения

- В `gate1-company-keyword-filter.js` добавлен чистый `g1CompanyQueryOverviewDerive(data, screen)`: он считает три числа итога, группы, поиск и сортировку только из входных данных и состояния экрана.
- В запросах добавлен статичный блок «Итог», четыре группы релевантности, колонки «Запрос / Близкие / Дальние / Соседи», сортировка по числовым колонкам и возврат к исходному порядку по заголовку «Запрос». Непроведённый поиск оставляет числовые ячейки пустыми; ноль проведённого поиска показан знаком «–».
- Обновление меняет только список строк, показатели под ним и состояние кнопок. Поле поиска остаётся тем же DOM-узлом, его фокус и позиция курсора сохраняются.
- В «Компаниях» добавлена только строка подсказки. Подключение в `gate1-company-analysis.js` не менялось.
- Стили нового вида находятся в `gate1-company-keyword-filter.css`; проектные данные, модели готовности и другие блоки не изменялись.

## Проверки

- `npm run build` в копии репозитория: пройдено, 49 совпадающих ресурсов, сборка `2.3.526+269e4444d9a8`. Копия использована, чтобы сборка не перезаписала файлы в рабочем дереве.
- `node --check gate1-company-keyword-filter.js`: пройдено.
- Существующий `gate1-company-query-relevance-smoke.mjs`: пройдено.
- Существующий `gate1-company-keyword-filter-smoke.mjs`: 4 из 4 проектов пройдено. Он сравнил сериализованный экспорт до и после действий в «Компаниях» (включая поля времени), DOM вне двух раскрывашек, проценты Gate 1, текущий шаг и «Не хватает».
- Новый браузерный smoke: 4 из 4 проектов пройдено. Проверены одинаковые SHA-256 сериализованного состояния до и после действий в «Запросах», неизменность DOM «Компаний», фокус и курсор поиска, сортировки, раскрытие строки, пустой результат и отсутствие ошибок JavaScript. Синтетическая проверка `derive` подтвердила порядок сортировки, итоговые числа и отсутствие изменений входного объекта.
- Для доступного снимка «Коричного яблока»: итог `0 + 2 + 13 = 15`; для остальных трёх снимков поисковых запросов нет, итог `0 + 0 + 0 = 0`. Хэши экспортов до/после совпадают для всех четырёх проектов; детали в `../company-keyword-filter/smoke-results.json` и `results.json`.
