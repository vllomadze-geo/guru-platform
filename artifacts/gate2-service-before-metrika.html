Настройки счётчика

Автоматические цели

Метрика сама создаёт цели на клики по телефону, email и подобные действия, без ручной настройки.

Вебвизор сайта

Запись движений мыши, скролла и кликов посетителя. Нужно для диагностики поведения на карточках товара.

Электронная коммерция

Настройка:

  1. Метрика → Настройки → Счётчик → Электронная коммерция → Вкл, контейнер dataLayer.
  2. Карточка товара подключена к блоку «Каталог товаров».
  3. Блок корзины (ST100) → Доп. настройки → галочка «Отправлять данные о добавлении в корзину».
  4. Опубликовать все страницы Tilda.

Проверка:

  • URL товара + ?_ym_debug=1, консоль (Cmd+Option+J), выполнить действие.
  • Просмотр карточки → событие detail с ID товара. Нет → карточка не подключена к каталогу.
  • В корзину → событие add. Нет → не включена галочка в ST100.
  • Оформление заказа → событие purchase с суммой и ID. Нет → не опубликованы страницы после включения опции.

Сверка:

Метрика → Отчёты → Электронная коммерция, тестовый заказ должен появиться там с задержкой до нескольких минут.

Контентная аналитика

Отчёты по текстовым материалам сайта — какой контент вовлекает аудиторию.

Тег менеджер

Нужен для правил, которых нет в панели «Аналитика» конструктора (там только вставка номеров счётчиков). Пример: показать пиксель ретаргетинга не всем, а только тем, кто провёл на странице больше 30 сек, или тем, кто дошёл до оплаты и не завершил (брошенная корзина). Если тумблер «Вкл», но пользовательский код не добавлен — функционально ничего не делает.

Проверка счётчика

Настройки → указать адрес страницы → «Проверить»)

Если код счётчика установлен корректно появится зелёное уведомление.

Если счётчик не найден уведомления не будет вообще (частые причины: блокировщик рекламы, счётчик удалён со страницы, редирект без передачи URL-параметров).

Главная цель конверсии (Спасибо-страница)Не начато

Настройка:

  1. Метрика → Цели → Добавить цель → тип «Посещение страниц».
  2. Условие: URL «Содержит» + адрес страницы благодарности, без протокола (http:///https:// ломают совпадение).
  3. Все формы и корзина сайта должны вести на одну и ту же страницу благодарности после отправки.

Проверка:

  • Отправить тестовую заявку или заказ с реального устройства.
  • Дождаться редиректа на страницу благодарности.
  • Через 15-30 минут открыть Метрика → Конверсии, проверить прирост «Достижения цели».

Сверка:

Метрика → Конверсии → цель по названию, прирост должен совпадать с числом тестовых отправок.
