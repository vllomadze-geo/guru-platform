# 3.3.4. Количество просмотров страниц

## 1. Что сделать (инструкция)

Настроить Яндекс Метрику для регистрации визитов, в которых посетитель просмотрел определённое количество страниц сайта, и проверить корректность достижения цели.

Целевое действие: посетитель достиг установленного порога просмотров страниц за один визит.

Приоритет: поведенческая конверсия.

Различайте:

| Показатель        | Что подтверждает                                  |
| ----------------- | ------------------------------------------------- |
| Просмотры         | Общее число зарегистрированных просмотров страниц |
| Глубина просмотра | Количество просмотров за один визит               |
| Достижение цели   | Визит достиг установленного порога просмотров     |
| Покупка           | Посетитель совершил коммерческое действие         |

Практическая ценность: выделять посетителей, изучающих несколько страниц, сравнивать их поведение с другими группами и оценивать связь глубины просмотра с заявками или покупками.

Яндекс Метрика автоматически рассчитывает глубину просмотра. Отдельная цель требуется только для использования конкретного порога как конверсии.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://yandex.ru\&sz=32)

Яндекс+2



Важные ограничения:

- Количество просмотров не равно количеству уникальных страниц.
- Повторное открытие страницы может увеличивать глубину.
- Виртуальные просмотры, отправленные сайтом, также могут учитываться.
- Большая глубина просмотра не всегда означает заинтересованность: пользователь может испытывать трудности с навигацией.

Правило GURU: порог определяем по фактической статистике проекта. Универсальное значение в 2, 3 или 5 просмотров не устанавливаем без обоснования.

Если подходящая цель уже существует, повторно её не создаём.

## 2. Где нажать / Как проверить (инструкция)

### А. Проверить существующую цель в Яндекс Метрике

1. Откройте [https://metrika.yandex.ru/](https://metrika.yandex.ru/?utm_source=chatgpt.com).
2. Войдите через рабочий Яндекс ID.
3. Выберите счётчик нужного сайта.
4. В левом меню нажмите «Цели».
5. Просмотрите существующие цели.
6. Найдите цель «Количество просмотров страниц», «Просмотр нескольких страниц» или цель с аналогичным назначением.
7. Если цель найдена, откройте её настройки.
8. Посмотрите установленный порог просмотров.
9. Запишите название, числовой ID и порог.

Если подходящая цель уже существует: новую не создавайте. Переходите к проверке.

Если цель отсутствует: сначала изучите реальные данные, чтобы определить обоснованный порог.

### Б. Изучить глубину просмотра

Часть 1. Открыть отчёт

1. Откройте [Яндекс Метрику](https://metrika.yandex.ru/?utm_source=chatgpt.com).
2. Выберите нужный счётчик.
3. В левом меню нажмите «Отчёты».
4. Найдите категорию «Аудитория».
5. Откройте «Глубина просмотра».
6. Установите период «Последние 30 дней», если за это время накоплены данные.
7. Убедитесь, что дополнительные сегменты не выбраны.

Этот отчёт показывает распределение визитов по глубине просмотра.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://yandex.ru\&sz=32)

Яндекс



Часть 2. Проанализировать результаты

Посмотрите, сколько визитов приходится на разную глубину просмотра.

| Глубина     | Что означает                                |
| ----------- | ------------------------------------------- |
| 1 просмотр  | Зафиксирован один просмотр страницы         |
| 2 просмотра | Зафиксированы два просмотра за визит        |
| 3 просмотра | Зафиксированы три просмотра                 |
| 4 и более   | Зафиксировано более глубокое взаимодействие |

При наличии достаточной статистики сравните группы по основным конверсиям: заказам, заявкам или другим подтверждённым коммерческим действиям.

Часть 3. Выбрать порог

Порог имеет смысл установить, если:

1. При его достижении заметно меняется вероятность основной конверсии.
2. Таких визитов достаточно для последующего анализа.
3. Показатель не определяется преимущественно техническими событиями сайта.

Например, если посетители с тремя и более просмотрами значительно чаще оформляют заказы, три просмотра можно рассматривать как кандидат на порог.

Это пример методики, а не готовое значение для проекта.

Если данные не позволяют определить значимый порог: отдельную цель пока не создаём. Продолжаем использовать стандартный отчёт.

### В. Проверить особенности Tilda

Часть 1. Проверить подключение счётчика

1. Откройте [https://tilda.cc/login/](https://tilda.cc/login/?utm_source=chatgpt.com).
2. Выберите нужный проект.
3. Перейдите в «Настройки сайта» → «Аналитика».
4. Найдите раздел «Яндекс Метрика».
5. Посмотрите номер подключённого счётчика.
6. Сравните его с номером в Метрике.

Если счётчик уже работает, ничего менять не требуется.

Часть 2. Проверить виртуальные просмотры

Tilda может отправлять виртуальные просмотры при открытии Pop-up, взаимодействии с кнопками, формами и товарами.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://help-ru.tilda.cc\&sz=32)

Справочный центр Tilda



Например:

`/tilda/popup/recXXXXXXXXX/opened`

`/tilda/product/detail/XXXXXXXXX`

Такие события могут увеличивать количество зарегистрированных просмотров.

Как проверить:

1. Откройте опубликованный сайт.
2. Добавьте к URL `_ym_debug=2`.
3. Откройте панель отладки Метрики.
4. Перейдите во вкладку `Console`.
5. Включите `Preserve log`.
6. Откройте обычную страницу сайта.
7. Затем откройте Pop-up или карточку товара.
8. Проверьте, появился ли дополнительный `PageView`.
9. Запишите, какое действие его вызвало.

Важно: виртуальный просмотр не обязательно является ошибкой. Но его необходимо учитывать при выборе порога.

Для `k-apple.ru` дополнительный скрипт поиска T985 не устанавливался. Поэтому обычный ввод поискового запроса не следует считать отдельным просмотром, пока его передача не подтверждена.

### Г. Создать цель «Количество просмотров страниц»

Выполняйте только после выбора обоснованного порога и проверки существующих целей.

Часть 1. Открыть создание цели

1. Откройте [https://metrika.yandex.ru/](https://metrika.yandex.ru/?utm_source=chatgpt.com).
2. Выберите нужный счётчик.
3. В левом меню нажмите «Цели».
4. Нажмите «Добавить цель».
5. В окне «Новая цель» найдите категорию «Вовлечённость».
6. Выберите «Количество просмотров страниц».

В официальной документации Яндекса этот тип сокращённо называется «Количество просмотров».&#x20;

2. Найдите поле «Просмотры».
3. Введите выбранное число.

Например: `3`, только если именно такой порог обоснован анализом.

4\. Проверьте введённые значения.

Ожидаемый результат: создана цель, которая регистрирует достижение выбранной глубины просмотра.

Повторно публиковать сайт Tilda не требуется, если счётчик уже работает.

### Д. Подготовить контрольную проверку

Часть 1. Зафиксировать исходный показатель

1. Откройте Яндекс Метрику.
2. Выберите нужный счётчик.
3. Перейдите в «Конверсии».
4. Установите период «Сегодня».
5. Найдите созданную цель.
6. Посмотрите показатель «Достижения цели».
7. Запишите его значение.

Часть 2. Подготовить браузер

1. Откройте Chrome в режиме инкогнито.
2. На Mac нажмите `Command + Shift + N`.
3. На Windows нажмите `Ctrl + Shift + N`.
4. Не авторизуйтесь в Метрике в этом окне.
5. Откройте опубликованный сайт.

Используйте одно окно и одну вкладку, чтобы выполнить контрольные переходы в рамках одного визита.

### Е. Выполнить контрольные просмотры

Пример для порога 3 просмотра.

1. Откройте главную страницу сайта.
2. Дождитесь её полной загрузки.
3. Через меню перейдите в каталог.
4. Дождитесь загрузки каталога.
5. Через ссылку перейдите на третью страницу.
6. Дождитесь полной загрузки.

Ожидаемый результат: за один визит зарегистрированы три просмотра страниц.

Для `k-apple.ru` можно использовать:

1. `https://k-apple.ru/`
2. `https://k-apple.ru/novogodnie-podarki-2027`
3. `https://k-apple.ru/individualnyj_zakaz`

Переходите по ссылкам сайта, не открывая каждую страницу в новом приватном окне.

Если выбран другой порог: выполните соответствующее число просмотров.

Не открывайте дополнительные Pop-up и не обновляйте страницы без необходимости, чтобы избежать лишних просмотров.

### Ж. Проверить регистрацию просмотров

1. Откройте страницу с `_ym_debug=2`.
2. Внизу откройте панель отладчика Метрики.
3. Перейдите во вкладку `Counters`.
4. Проверьте номер счётчика.
5. Перейдите во вкладку `Console`.
6. Найдите запись `PageView`.
7. Проверьте, что она относится к правильной странице.

Затем таким же способом можно проверить остальные страницы, если возникают сомнения в передаче просмотров.

Важно: `PageView` подтверждает отправку просмотра. Достижение установленного порога необходимо дополнительно подтвердить в отчёте.

Источник: [Яндекс, проверка целей](https://yandex.ru/support/metrica/ru/general/check-goal?utm_source=chatgpt.com).

### З. Проверить достижение цели

1. Откройте [https://metrika.yandex.ru/](https://metrika.yandex.ru/?utm_source=chatgpt.com).
2. Выберите нужный счётчик.
3. В левом меню нажмите «Конверсии».
4. Установите период «Сегодня».
5. Убедитесь, что дополнительные сегменты не выбраны.
6. Найдите цель по названию или числовому ID.
7. Проверьте показатели «Целевые визиты» и «Достижения цели».
8. Сравните их с показателями до теста.

Ожидаемый результат: после обработки данных контрольный визит учитывается как целевой.

Если сайт посещают другие пользователи, изменение суммарных показателей может быть связано и с их действиями.

Если достижения нет:

1. Проверьте установленный порог.
2. Убедитесь, что просмотры выполнялись в рамках одного визита.
3. Проверьте передачу `PageView`.
4. Проверьте номер счётчика.
5. Проверьте выбранный период отчёта.
6. Откройте настройки счётчика и проверьте фильтры визитов.
7. Дождитесь обработки данных и повторите проверку.

Не создавайте новую цель вместо существующей, пока причина ошибки не установлена.

### И. Проверить достоверность данных

Часть 1. Исключить технические дубли

1. Откройте страницу сайта с активным отладчиком.
2. Проверьте, сколько просмотров регистрируется при обычной загрузке.
3. Если появляются дополнительные `PageView`, определите их источник.
4. Проверьте, не связано ли увеличение с Pop-up, товарным окном или пользовательским скриптом.

Часть 2. Сравнить с реальной активностью

1. Откройте отчёт «Глубина просмотра».
2. Посмотрите распределение визитов после настройки.
3. Сравните его с данными до создания цели.
4. Убедитесь, что выбранный порог по-прежнему имеет аналитический смысл.

Важно: не исправляйте существующие события Tilda исключительно ради увеличения или уменьшения показателя глубины просмотра.

### К. Определить использование в Яндекс Директе

После успешной проверки:

1. Откройте Метрику → «Цели».
2. Найдите созданную цель.
3. Зафиксируйте её ID.
4. Убедитесь, что зарегистрированы достижения.
5. Определите назначение цели как вспомогательной поведенческой конверсии.

Не назначайте её основной целью оптимизации Яндекс Директа автоматически.

Приоритет остаётся за заказами, заявками и другими подтверждёнными коммерческими конверсиями.

### Итоговый результат

Готово

- Порог выбран по фактическим данным.
- Цель создана либо использована существующая.
- Метрика регистрирует просмотры страниц.
- Достижение подтверждено в отчёте.
- Нет нежелательного дублирования.

Требует проверки

- Достижение ещё не появилось в отчёте.
- Не установлено влияние виртуальных просмотров.
- Недостаточно данных для определения порога.

Проблема

- Указан неправильный порог.
- Счётчик не регистрирует просмотры.
- Есть нежелательные дубли событий.
- Достижения не соответствуют ожидаемому поведению после проверки и обработки данных.

Не требуется

Цель не имеет самостоятельной аналитической ценности либо достаточно стандартного отчёта «Глубина просмотра».

### Результат для аналитики

- Назначение: анализ глубины взаимодействия с сайтом.
- Приоритет: поведенческая конверсия.
- Тип цели: «Количество просмотров страниц».
- Механизм: достижение заданного количества просмотров за визит.
- Ограничение: глубина просмотра не равна количеству уникальных страниц и сама по себе не подтверждает коммерческий интерес.
- Использование: сегментация посетителей, сравнение источников трафика и изучение связи вовлечённости с основными конверсиями.

После подтверждения правильной регистрации цели можно переходить к 3.3.5. Продолжительность визита.
