# 3.3. Проверка поисковой видимости и позиций

## 1. Что сделать (инструкция)

Подтвердить, что приоритетные страницы сайта фактически показываются в поисковой выдаче Яндекса и занимают измеряемые позиции по поисковым запросам.

**Зачем:** наличие страницы в поисковой базе ещё не подтверждает, что пользователи видят её в результатах поиска. Необходимо проверить фактическое участие страницы в ранжировании.

**Целевое действие:** получить первоначальные показатели поисковой видимости каждой приоритетной страницы и зафиксировать результаты.

**Ожидаемый результат:**

- Подтверждены показы страниц в поиске Яндекса.
- Определены средние позиции за выбранный период.
- Зафиксированы клики и CTR.
- По возможности установлены поисковые запросы, по которым отображаются страницы.
- Сохранены исходные показатели для дальнейшего анализа в Гейте 5.

**Приоритет:** первоначальная проверка готовности к органическому поисковому трафику.

Для выполнения этого шага не требуется достижение определённой позиции, количества кликов или CTR. Необходимо подтвердить сам факт ранжирования.

Если подтверждённая статистика уже получена и соответствует проверяемой странице, повторно выполнять анализ за тот же период не нужно.

Регулярное наблюдение за позициями, оценка динамики и SEO-оптимизация относятся к Гейту 5.

## 2. Где нажать / Как проверить (инструкция)

### А. Подготовить список страниц

1. Возьмите из проекта список приоритетных страниц, для которых необходимо привлекать органический поисковый трафик.
2. Используйте окончательные URL, подтверждённые в шагах 3.1 и 3.2.
3. Выберите одну страницу для проверки.
4. Скопируйте её полный адрес.
5. Убедитесь, что предыдущие проверки индексации этой страницы завершены.
6. Проверьте, не были ли показатели поисковой видимости уже зафиксированы.

**Пример для проекта «Коричное яблоко»:**

`https://k-apple.ru/simvol-2027-koza`

Если данные по этой странице уже имеются, используйте их как первоначальный результат.

Не создавайте новые цели Яндекс Метрики, группы поисковых запросов или настройки сайта ради получения статистики Вебмастера.

### Б. Открыть «Статистику страниц»

1. Перейдите на https://webmaster.yandex.ru/.
2. Авторизуйтесь через Яндекс ID, имеющий доступ к сайту.
3. В левом верхнем углу выберите сайт проекта.
4. В левом меню раскройте «Эффективность».
5. Нажмите **«Статистика страниц»**.
6. Дождитесь загрузки отчёта.
7. Убедитесь, что выбран правильный домен.

**Ожидаемый результат:** открывается отчёт с графиком, таблицей страниц и показателями поисковой эффективности.

### В. Выбрать проверяемую страницу

**Способ 1. Через таблицу**

1. Найдите нужный URL в таблице страниц.
2. Нажмите на его адрес.
3. Дождитесь открытия подробного отчёта.
4. Убедитесь, что выбран именно нужный URL.

**Способ 2. Через список страниц**

1. Над графиком найдите раскрывающийся список **«Все страницы»**.
2. Нажмите на него.
3. Начните вводить путь проверяемой страницы.
4. Выберите подходящий URL из появившегося списка.
5. Убедитесь, что адрес отображается в верхнем фильтре.

**Пример:**

`/simvol-2027-koza`

Важно: проверять необходимо конкретную страницу, а не общую статистику всего сайта.

Если нужного URL нет в списке, это ещё не доказывает отсутствие ранжирования. В отчёте Яндекса представлены до 3000 страниц, появлявшихся на позициях с 1-й по 50-ю.

### Г. Установить параметры отчёта

**Часть 1. Период**

1. Найдите поле с диапазоном дат над графиком.
2. Нажмите на него.
3. Выберите последний доступный период продолжительностью около 30 дней.
4. Если за него данных недостаточно, расширьте диапазон на доступный более ранний период.
5. Запишите точные даты начала и окончания.

Используйте данные последнего доступного периода, а не обязательно последние 30 календарных дней, если статистика обновляется с задержкой.

**Часть 2. Устройства**

1. Найдите список **«Все устройства»**.
2. Оставьте этот вариант для общей первоначальной проверки.
3. Не ограничивайте отчёт компьютерами или смартфонами, если такое разделение не требуется.

**Часть 3. Регион**

1. Найдите поле «Регион или страна».
2. Проверьте доступные варианты.
3. Если требуется общая первоначальная статистика, оставьте поле без дополнительного ограничения.
4. Если анализируется определённый регион и он есть в списке, выберите его.
5. Если нужного региона нет, не заменяйте его другим без основания.

Например, если проект ориентирован на Москву, но в списке доступен только Центральный федеральный округ, не следует выдавать его показатели за статистику исключительно Москвы.

**Часть 4. Детализация**

1. Найдите список «Детализация».
2. Для короткого периода выберите «По дням».
3. Убедитесь, что график соответствует выбранным датам.

### Д. Получить первоначальные показатели

1. Под графиком найдите таблицу «Показатель».
2. В колонке «Всего» найдите строку **«Показы»**.
3. Запишите количество показов.
4. Найдите **«Клики»** и зафиксируйте значение.
5. Найдите **«CTR, %»**.
6. Найдите **«Ср. позиция»**.
7. Найдите **«Ср. позиция клика»**.
8. В разделе «Показы на позициях» посмотрите количество показов на каждой группе позиций.
9. Сравните сумму показов по группам с общим количеством показов.
10. Зафиксируйте дату получения отчёта.

**Что означают показатели:**

| Показатель | Что подтверждает |
|---|---|
| Показы | Страница появлялась перед пользователями в результатах поиска |
| Клики | Пользователи переходили на страницу из поиска |
| CTR | Доля кликов относительно показов |
| Средняя позиция | Усреднённое положение страницы в результатах поиска |
| Средняя позиция клика | Положение страницы в момент перехода пользователя |
| Показы на позициях | Распределение видимости по диапазонам позиций |

**Критически важно:**

- Показы больше нуля подтверждают фактическую поисковую видимость за указанный период.
- Ноль кликов при наличии показов не означает неисправность страницы.
- Средняя позиция не является текущей позицией по конкретному запросу.
- Отсутствие статистики не доказывает, что страница отсутствует в поисковой базе.

Статистика Вебмастера учитывает показы и клики в пределах первых 50 позиций поисковой выдачи.

### Е. Проверить поисковые запросы

Выполняйте при доступности инструмента «Мониторинг запросов». Этот раздел позволяет дополнить подтверждение поисковой видимости сведениями о запросах.

**Часть 1. Открыть инструмент**

1. Перейдите в Яндекс Вебмастер.
2. Выберите сайт проекта.
3. В левом меню раскройте «Эффективность».
4. Нажмите **«Мониторинг запросов»**.

**Часть 2. Выбрать период**

В разделе «Интервал мониторинга» доступны:

- «По часам».
- «2 недели».
- «18 месяцев».

Для первоначальной проверки выберите «2 недели». Если данных недостаточно, попробуйте «18 месяцев» для исторической статистики.

При выборе 18 месяцев Яндекс показывает средние значения по месяцам, а не ежедневные позиции.

**Часть 3. Настроить фильтр страницы**

1. Установите «Все устройства».
2. Оставьте поле «Регион или страна» без ограничения, если нужный регион недоступен.
3. Нажмите **«Фильтры»**.
4. В первом списке выберите **«URL»**.
5. Во втором списке выберите **«Включает»**.
6. Введите уникальную часть пути страницы без домена.

   Например:

   `simvol-2027-koza`

7. Нажмите **«Применить»**.
8. Убедитесь, что под фильтрами появилось условие `URL содержит simvol-2027-koza`.

**Важно:** при переключении периода фильтр может сбрасываться. После изменения периода обязательно проверьте, остался ли он активным.

**Часть 4. Просмотреть запросы**

1. Над таблицей выберите **«Запрос»**.
2. Найдите поисковые фразы, по которым отображалась страница.
3. Посмотрите доступные показатели позиций, показов и кликов.
4. Сравните отображаемый под запросом URL с проверяемой страницей.
5. Зафиксируйте только подтверждённые данные.

**Ограничение:** в представлении «Запрос» Яндекс показывает наиболее частотный по показам URL для запроса. При фильтрации таблица может отображать другие URL. Поэтому не приписывайте конкретной странице позицию, если связь запроса с ней не подтверждена.

### Ж. Если нужна точная связь запроса и страницы

Используйте **«Расширенную аналитику поисковых запросов по URL (β)»**, если инструмент доступен.

1. Откройте Яндекс Вебмастер.
2. Выберите сайт проекта.
3. Перейдите в «Эффективность».
4. Нажмите «Расширенная аналитика поисковых запросов по URL (β)».
5. Выберите диапазон дат.
6. Укажите доступный подходящий регион.
7. Введите полный URL проверяемой страницы в поле списка URL.
8. Нажмите **«Подготовить аналитику»**.
9. Найдите созданный отчёт в таблице ниже.
10. После завершения подготовки нажмите **«Показать»**.
11. Нажмите **«Скачать»**.
12. Откройте CSV-файл.

В отчёте сравните колонки:

- Дата.
- URL.
- Запрос.
- Регион.
- Показы.
- Клики.
- Позиция.

Базовый лимит: 100 запросов в день. Один URL за один день отчёта расходует одну единицу лимита.

Для первоначальной проверки одной страницы достаточно короткого интервала, если он содержит данные. Платный доступ специально для завершения Гейта 2 приобретать не требуется.

**Если инструмент недоступен:** зафиксируйте сообщение Яндекса и используйте уже полученные результаты «Статистики страниц».

Отсутствие подробного списка запросов не отменяет подтверждённые показы и позиции страницы.

### З. Если данные отсутствуют или инструменты недоступны

**Ситуация 1. Страница отсутствует в «Статистике страниц»**

1. Проверьте выбранный домен.
2. Убедитесь, что указан правильный URL.
3. Уберите ограничения региона.
4. Установите «Все устройства».
5. Расширьте период.
6. Повторите проверку.
7. Если данных нет, зафиксируйте отсутствие подтверждённых показов за выбранный период.

Не устанавливайте значение позиции «0», если Яндекс её не определил.

**Ситуация 2. «Мониторинг запросов» показывает пустую таблицу**

1. Проверьте наличие URL-фильтра.
2. Убедитесь, что условие «Включает» использует правильный путь.
3. Проверьте период.
4. Убедитесь, что регион не ограничивает результаты.
5. Повторно примените фильтр.
6. Сравните результаты со «Статистикой страниц».

Если в «Статистике страниц» есть показы, а в «Мониторинге запросов» данных нет, зафиксируйте расхождение. Не делайте вывод об отсутствии ранжирования.

**Ситуация 3. Яндекс сообщает о технической недоступности**

1. Зафиксируйте название инструмента.
2. Сохраните дату и текст сообщения.
3. Используйте другой доступный отчёт.
4. Сохраните подтверждённые исторические показатели.
5. Неполученные данные обозначьте как неподтверждённые.

Не изменяйте Tilda, Sitemap, Яндекс Метрику или настройки индексирования ради исправления ошибки аналитического сервиса Яндекса.

**Ситуация 4. Аналитических данных нет, но необходимо проверить фактическую выдачу**

1. Откройте https://yandex.ru/.
2. Введите релевантный поисковый запрос, соответствующий странице.
3. Проверьте результаты поиска.
4. Если найден нужный URL, запишите запрос, дату, регион, устройство и наблюдаемое расположение.
5. Сохраните скриншот.

Ручная проверка подтверждает наблюдаемое присутствие страницы по конкретному запросу на момент поиска. Она не заменяет статистику средней позиции и не гарантирует устойчивого ранжирования.

Оператор `url:` для проверки наличия страницы в индексе уже рассмотрен в шаге 3.1. Повторять его как доказательство коммерческого ранжирования не требуется.

### И. Зафиксировать результат

Для каждой приоритетной страницы сохраните:

1. Полный URL.
2. Период статистики.
3. Дату проверки.
4. Количество показов.
5. Количество кликов.
6. CTR.
7. Среднюю позицию.
8. Среднюю позицию клика, если она определена.
9. Подтверждённые поисковые запросы, если доступны.
10. Ограничения данных, если имеются.

Если требуется выгрузка:

1. В «Статистике страниц» найдите кнопки **«XLS»** и **«CSV»** внизу таблицы.
2. Выберите подходящий формат.
3. Сохраните файл.
4. Убедитесь, что выгруженные данные соответствуют выбранной странице и периоду.

**Сохранение настроек:** этот шаг является проверкой. Изменять и публиковать сайт, создавать цели или добавлять код не требуется.

Переходите к следующему приоритетному URL после фиксации результата текущего.

## 3. Сверка (инструкция)

| Проверка | Правильный результат |
|---|---|
| Основной домен | Совпадает с проектом |
| Приоритетная страница | Совпадает с окончательным URL проекта |
| Индексация | Подтверждена предыдущими шагами |
| Период | Указаны точные даты |
| Устройства | Выбрана нужная аудитория |
| Регион | Корректный или без ограничения |
| Показы | Есть фактические данные, если страница показывалась |
| Клики | Зафиксированы без требования положительного значения |
| CTR | Соответствует данным Вебмастера |
| Средняя позиция | Определена за выбранный период |
| Поисковые запросы | Связь с URL подтверждена, если данные доступны |
| Исторические показатели | Не выдаются за текущие |
| Ошибки инструментов | Зафиксированы отдельно |
| Повторные настройки | Не создавались |

### Готово

- Проверены все обязательные приоритетные страницы проекта.
- Для каждой подтверждено первоначальное ранжирование фактическими данными Вебмастера.
- Зафиксированы показы и средние позиции за конкретный период.
- Параметры отчётов соответствуют проекту.
- Полученные результаты сохранены.

Клики могут равняться нулю. Попадание в ТОП-10 не является обязательным условием.

### Требует проверки

- По части страниц нет подтверждённых показов или позиций.
- Инструменты Яндекса временно недоступны.
- Имеются только наблюдения ручной выдачи без достаточной статистики.
- Данные относятся к неправильному периоду либо URL.
- Не все приоритетные страницы проверены.

Отсутствие показов не означает автоматически, что сайт технически неисправен.

### Проблема

- Анализ выявил, что вместо приоритетной страницы отображается ошибочный URL.
- Обнаружены несоответствия между фактическим адресом и страницей проекта.
- Дополнительная проверка установила техническое препятствие ранжированию.

Подтверждённые технические ошибки устраняются в соответствующих предыдущих шагах. Задачи повышения позиций и улучшения содержания передаются в Гейт 5.

### Подтверждённые данные проекта «Коричное яблоко»

**Проверяемая страница:**  
`https://k-apple.ru/simvol-2027-koza`

**Период:** 6 сентября - 6 октября 2026 года.

| Показатель | Результат |
|---|---:|
| Показы | 24 |
| Клики | 1 |
| CTR | 4,16% |
| Средняя позиция | 10,08 |
| Средняя позиция клика | 11 |
| Показы на позиции 1 | 0 |
| Показы на позициях 2-3 | 1 |
| Показы на позициях 4-10 | 12 |
| Показы на позициях 11-50 | 11 |

**Дополнительно установлено:**

- 13 из 24 показов приходятся на первые 10 позиций.
- Единственный клик зарегистрирован с 11-й позиции.
- В предыдущих исторических отчётах встречались запросы «коза текстильная», «козы текстильные», «коза из текстиля» и «козлёнок текстильный» с позициями приблизительно 10-13.
- Полная привязка этих запросов к конкретной странице в доступных отчётах не подтверждена.

**Ограничения на 11 ноября 2026 года:**

- «Мониторинг запросов» сообщает о временной приостановке обновления данных.
- После применения URL-фильтра за 18 месяцев результаты отсутствуют.
- «Расширенная аналитика поисковых запросов по URL (β)» временно недоступна.
- Актуальные позиции по отдельным запросам на дату проверки не определены.

**Вывод:** первоначальное ранжирование страницы `/simvol-2027-koza` за указанный исторический период подтверждено. Данных недостаточно для оценки устойчивости позиций и актуальной динамики.

Повторно выполнять те же проверки за уже зафиксированный период не требуется.

### Результат для аналитики

- **Назначение:** первоначальное подтверждение поискового ранжирования.
- **Основной инструмент:** «Статистика страниц».
- **Дополнительный инструмент:** «Мониторинг запросов».
- **Уточняющий инструмент:** «Расширенная аналитика поисковых запросов по URL (β)».
- **Главный критерий:** фактические показы и измеряемая средняя позиция приоритетной страницы.
- **Основное ограничение:** статистика относится к выбранному периоду, а не к гарантированной текущей позиции.
- **Постоянный мониторинг:** Гейт 5 «Оценка и оптимизация (постоянная петля)».

**После проверки первоначального ранжирования всех обязательных страниц можно завершить шаг 3.3 и подтвердить выполнение раздела 3 «Первичная проверка индексации и ранжирования».**
