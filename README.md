# GURU Platform v1.1.11 — Контрольная дата фиксации

## Запуск с облачной синхронизацией

Для работы Supabase запускайте приложение через API-сервер:

```bash
npm start
```

Не используйте `serve .`, Live Server или открытие `index.html` двойным
кликом: это статические серверы, они не обслуживают `/api/workspace-sync` и
`/api/supabase-test`, поэтому облачная синхронизация получит HTTP 404.
