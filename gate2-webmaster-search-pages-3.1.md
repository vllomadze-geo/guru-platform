# 3.1. Страницы в поиске

## 1. Что сделать (инструкция)

Проверить, что приоритетные страницы опубликованного сайта присутствуют в поисковой базе Яндекса.

**Зачем:** подключение Яндекс Вебмастера, доступность страниц и корректный Sitemap не гарантируют, что поисковый робот включил страницы в результаты поиска.

**Целевое действие:** подтвердить фактическое присутствие каждой приоритетной страницы проекта в поиске Яндекса.

**Ожидаемый результат:** получено подтверждение индексации обязательных страниц, определены отсутствующие URL.

Если индексация страницы уже подтверждена актуальной проверкой, повторять её без необходимости не нужно.

**Важно:** на этом этапе проверяем только присутствие страниц в поиске. Технические причины исключения рассматриваются в шаге 3.2, а показы и позиции по поисковым запросам в шаге 3.3.

## 2. Где нажать / Как проверить (инструкция)

### А. Подготовить список страниц

1. Возьмите из проекта основной адрес сайта.
2. Определите опубликованные страницы, которые должны привлекать органический поисковый трафик: главную, основные категории, товары, услуги и приоритетные посадочные страницы.
3. Скопируйте полные URL этих страниц.
4. Откройте каждый URL в браузере и убедитесь, что он ведёт на нужную страницу.
5. Исключите технические страницы и другие URL, для которых индексирование намеренно не предусмотрено.
6. Если страница была перенесена, используйте окончательный адрес, а не старый URL с перенаправлением.

**Пример для проекта «Коричное яблоко»:**

`https://k-apple.ru/simvol-2027-koza`

Проверяемые URL должны определяться данными конкретного проекта, а не фиксированным списком из этой инструкции.

### Б. Открыть Яндекс Вебмастер

1. Перейдите на https://webmaster.yandex.ru/.
2. Войдите через Яндекс ID, имеющий доступ к сайту.
3. В левом верхнем углу выберите нужный сайт.
4. В левом меню нажмите «Индексирование».
5. В раскрывшемся меню выберите «Страницы в поиске».
6. Найдите переключатели:
   - «Последние изменения».
   - «Все страницы».
   - «Исключённые страницы».

**Основной режим проверки:** «Все страницы».

Если он доступен, нажмите его. В таблице отображаются страницы, которые Яндекс считает участвующими в поиске.

### В. Найти конкретную страницу

1. Над таблицей найдите колонку «Статус и URL».
2. Нажмите значок фильтра в виде воронки **слева от названия этой колонки**.
3. В появившемся меню выберите условие «Содержит».
4. Введите уникальную часть адреса проверяемой страницы.

   Например:

   `simvol-2027-koza`

5. Подтвердите ввод в фильтре.
6. Убедитесь, что под заголовком «Статус и URL» отображается применённое условие.
7. Найдите соответствующий URL в таблице.
8. Сравните его с адресом страницы из проекта.

**Важно:** если вместо «Содержит» выбран режим «Условие», Яндекс поддерживает специальные обозначения:

- `@simvol-2027-koza` означает, что URL содержит указанную строку.
- `~simvol-2027-koza` означает поиск по регулярному выражению.

Для обычного поиска используйте «Содержит». Если другой фильтр уже корректно нашёл нужный URL, менять его необязательно.

### Г. Проверить результат индексирования

**Если открыта вкладка «Все страницы»:**

1. Найдите нужный URL в таблице.
2. Убедитесь, что он соответствует основной опубликованной странице.
3. Посмотрите дату последнего посещения роботом.
4. Зафиксируйте результат.

Наличие URL в этой вкладке подтверждает участие страницы в поиске по данным Вебмастера.

**Если страница не найдена:**

1. Проверьте введённый фрагмент URL.
2. Удалите фильтр и повторите поиск.
3. Откройте вкладку «Исключённые страницы».
4. Найдите тот же URL.
5. Если он присутствует, зафиксируйте причину исключения.
6. Передайте обнаруженную проблему в шаг 3.2.

Не изменяйте robots.txt, canonical или настройки Tilda непосредственно в этом шаге.

### Д. Если доступны только «Последние изменения»

Иногда вкладки «Все страницы» и «Исключённые страницы» могут быть временно недоступны.

В этом случае:

1. Откройте «Последние изменения».
2. Примените фильтр «Статус и URL» для нужной страницы.
3. Найдите все отображаемые записи по этому URL.
4. Посмотрите даты обновления.
5. Зафиксируйте статусы в хронологическом порядке.
6. Определите последнее зарегистрированное изменение.

**Пример из проверки `k-apple.ru`:**

| Дата | Зарегистрированное состояние |
|---|---|
| 20.09.2026 | Каноническая |
| 23.09.2026 | Малоценная или маловостребованная |
| 26.09.2026 | Каноническая |

Последнее отображаемое изменение было положительным.

Однако «Последние изменения» являются историей событий. Они не гарантируют, что состояние страницы осталось прежним на дату проверки.

Поэтому при недоступности основного списка используйте альтернативную проверку.

### Е. Альтернативная проверка через Поиск Яндекса

Этот способ предусмотрен официальной документацией Яндекса.

1. Откройте https://yandex.ru/.
2. Нажмите на поисковую строку.
3. Введите оператор `url:` и сразу после него полный адрес страницы, без пробела.

   **Пример:**

   `url:https://k-apple.ru/simvol-2027-koza`

4. Нажмите Enter.
5. Дождитесь результатов поиска.
6. Найдите результат с проверяемой страницей.
7. Сравните адрес результата с URL из проекта.
8. Зафиксируйте дату проверки.

**Если страница найдена:**

Её присутствие в поисковой базе Яндекса подтверждено.

**Если страница не найдена:**

1. Проверьте правильность написания полного адреса.
2. Убедитесь, что использован окончательный URL, включая правильный домен и путь.
3. Повторите поиск, указав полный адрес без оператора `url:`.
4. Если страница по-прежнему не найдена, зафиксируйте отсутствие подтверждения индексации.
5. Перейдите к диагностике конкретного URL в шаге 3.2.

Не считайте отсутствие результата окончательным доказательством технической ошибки. Поисковая база и отчёты могут обновляться с задержкой.

### Ж. Зафиксировать результаты

Для каждой приоритетной страницы зафиксируйте:

1. Полный URL.
2. Дату проверки.
3. Источник: «Все страницы», «Последние изменения» или Поиск Яндекса с оператором `url:`.
4. Результат: найдена или не найдена.
5. Причину исключения, если она известна.

При необходимости сохраните скриншот результата.

Если выгрузка доступна в Вебмастере, используйте кнопки «XLS» или «CSV». Если кнопки неактивны из-за сбоя сервиса, зафиксируйте результат вручную.

**Сохранение настроек:** этот шаг не требует публикации сайта, создания целей, изменения Sitemap или повторного подключения Вебмастера.

## 3. Сверка (инструкция)

| Проверка | Правильный результат |
|---|---|
| Основной домен | Совпадает с доменом проекта |
| Проверяемые страницы | Соответствуют приоритетным URL проекта |
| Адрес страницы | Совпадает с окончательным опубликованным URL |
| «Все страницы» | Нужный URL присутствует |
| Альтернативная проверка | Поиск `url:` возвращает нужную страницу |
| Исторические изменения | Не принимаются автоматически за текущий статус |
| Исключённые страницы | Причины отсутствия зафиксированы, если доступны |
| Дата проверки | Указана для каждого результата |
| Дублирование настроек | Отсутствует |

### Готово

- Проверены все обязательные приоритетные страницы проекта.
- Присутствие каждой из них в поиске Яндекса подтверждено.
- Результаты и даты проверки зафиксированы.

### Требует проверки

- Часть страниц ещё не проверена.
- Сервис Яндекса временно недоступен.
- Страница не найдена, но причина отсутствия пока неизвестна.
- Имеются только исторические сведения, не подтверждающие текущее состояние.

### Проблема

- Обязательная страница подтверждённо исключена из поиска.
- Обнаружено, что вместо необходимой страницы в поиске находится неправильный URL.
- Выявлено препятствие индексированию, требующее отдельного устранения.

Причину и действия по исправлению передайте в шаг 3.2.

### Подтверждённый результат для проекта «Коричное яблоко»

**Проверенная страница:**  
`https://k-apple.ru/simvol-2027-koza`

**Дата проверки:** 11 ноября 2026 года.

**Результаты:**

- В «Последних изменениях» 26 сентября зафиксирован статус «Каноническая».
- Вкладки «Все страницы» и «Исключённые страницы» временно недоступны.
- Инструмент «Проверка страницы» также временно недоступен.
- Проверка через оператор `url:` 11 ноября успешно нашла страницу в поиске Яндекса.
- Отображаемый заголовок соответствует странице проекта.

**Вывод:** присутствие страницы `/simvol-2027-koza` в поиске Яндекса на дату проверки подтверждено.

Для завершения всего шага 3.1 необходимо проверить остальные обязательные страницы проекта.

### Результат для аналитики

- **Назначение:** первоначальное подтверждение индексации.
- **Инструмент:** Яндекс Вебмастер и Поиск Яндекса.
- **Основной критерий:** присутствие обязательных URL в поисковой базе.
- **Ограничение:** наличие страницы в поиске не подтверждает её позиции по целевым запросам.
- **Следующий шаг:** 3.2. Проверка приоритетных URL.
- **Постоянный мониторинг:** Гейт 5 «Оценка и оптимизация».

**После подтверждения индексации всех обязательных страниц можно завершить шаг 3.1 и перейти к 3.2.**
