# 1.2. Подтверждение прав

## 1. Что сделать (инструкция)

Проверить действующие права доступа к сайту в Яндекс Вебмастере и при необходимости подтвердить право управления сайтом либо получить соответствующие полномочия от владельца.

**Целевое действие:** пользователь получил подтверждённый доступ к функциям Яндекс Вебмастера, необходимым для управления индексированием и анализа поисковой эффективности сайта.

Различайте:

| Роль | Что позволяет |
|---|---|
| Владелец | Полное управление сайтом и правами пользователей |
| Редактирование | Просмотр статистики и изменение настроек без управления правами |
| Просмотр | Изучение статистики без изменения настроек |
| Частичный доступ | Работа только с разрешёнными инструментами |

**Приоритет:** фундаментальная настройка.

Для самостоятельного подтверждения используем штатные способы Яндекс Вебмастера. Если сайт создан на Tilda, предпочтительно использовать встроенное подтверждение либо метатег.

Дополнительный JavaScript, установка Яндекс Метрики и создание нового сайта в Вебмастере не требуются, если необходимые права уже действуют.

**Важно:** владелец бизнеса должен сохранять полный доступ к сайту. Специалисту, занимающемуся SEO, достаточно роли «Редактирование» или необходимых частичных разрешений.

Если подходящие права уже предоставлены, повторно подтверждать владение не нужно.

## 2. Где нажать / Как проверить (инструкция)

### А. Найти существующий сайт в Яндекс Вебмастере

**Часть 1. Открыть сервис**

1. Откройте https://webmaster.yandex.ru/.
2. Войдите через рабочий Яндекс ID.
3. Откройте страницу **«Мои сайты»**.
4. Найдите поле поиска сайтов.
5. Введите домен нужного проекта.
6. Найдите сайт в появившемся списке.

Для проекта «Коричное яблоко»:

`https://k-apple.ru`

**Часть 2. Проверить существующее подключение**

1. Найдите строку сайта.
2. Проверьте полный адрес, включая `https://`.
3. Убедитесь, что адрес соответствует основному домену проекта.
4. Посмотрите, отображаются ли данные о состоянии сайта.
5. Проверьте отсутствие сообщения «Права на сайт не подтверждены».

**Ожидаемый результат:** сайт найден, его адрес совпадает с основным доменом.

Если сайт уже присутствует в списке, повторно добавлять его не требуется.

**Важно:** возможность просмотра сайта в Вебмастере не доказывает наличие роли «Владелец».

### Б. Проверить существующие права доступа

**Часть 1. Открыть управление доступом**

В обновлённом интерфейсе Яндекс Вебмастера:

1. Откройте https://webmaster.yandex.ru/sites/.
2. Найдите строку нужного сайта.
3. В правой части строки нажмите значок **«⋮»**.
4. В открывшемся меню выберите **«Управление доступом»**.
5. Дождитесь открытия страницы управления правами.

Альтернативный путь из официальной документации:

1. Выберите сайт.
2. Откройте **«Настройки»**.
3. Перейдите в **«Права доступа»**.

**Часть 2. Найти пользователей**

1. Найдите блок **«Список пользователей»**.
2. Просмотрите список Яндекс ID.
3. Найдите аккаунт, под которым вы вошли.
4. Посмотрите назначенную роль.
5. Если отображается статус подтверждения, проверьте его.
6. Зафиксируйте результат.

**Ожидаемый результат:** текущий пользователь найден, его роль и полномочия определены.

**Если назначена роль «Владелец»:** повторное подтверждение не требуется.

**Если назначена роль «Редактирование»:** проверьте, достаточно ли полномочий для последующих действий.

**Если права отсутствуют:** переходите к разделу Г.

### В. Проверить достаточность полномочий

Для работы GURU необходимы следующие возможности Яндекс Вебмастера.

| Инструмент | Необходимое действие |
|---|---|
| Страницы в поиске | Просматривать состояние индексирования |
| Проверка страницы | Анализировать конкретные URL |
| Мониторинг важных страниц | Добавлять страницы для контроля |
| Переобход страниц | Отправлять исправленные URL |
| Файлы Sitemap | Проверять и добавлять карты сайта |
| Статистика страниц | Анализировать показы, клики и CTR |
| Мониторинг запросов | Анализировать запросы и позиции |
| Диагностика сайта | Изучать ошибки и рекомендации |

**Порядок проверки:**

1. Откройте сайт в Яндекс Вебмастере.
2. В левом меню раскройте **«Индексирование»**.
3. Найдите «Страницы в поиске».
4. Откройте этот раздел.
5. Убедитесь, что статистика доступна.
6. Вернитесь в меню «Индексирование».
7. Откройте «Проверка страницы».
8. Проверьте доступность инструмента.
9. Раскройте раздел **«Эффективность»**.
10. Проверьте доступность статистики поисковых запросов.

**Ожидаемый результат:** пользователь может работать с инструментами, необходимыми для следующих этапов настройки.

**Важно:** на данном этапе не отправляйте страницы на переобход и не изменяйте Sitemap. Проверяется только наличие доступа.

**Если роль достаточна:** переходите к итоговой сверке.

**Если доступ ограничен:** переходите к получению прав.

### Г. Получить права от существующего владельца

Выполняйте, если у пользователя нет необходимых полномочий, но сайт уже управляется другим владельцем.

**Часть 1. Определить владельца**

1. Откройте «Управление доступом».
2. Найдите «Список пользователей».
3. Посмотрите, какой Яндекс ID имеет роль «Владелец».
4. Обратитесь к этому пользователю с запросом на предоставление доступа.

**Часть 2. Предоставить права**

Следующие действия выполняет владелец:

1. Открывает https://webmaster.yandex.ru/.
2. Выбирает нужный сайт.
3. Переходит в **«Настройки» → «Права доступа»**.
4. Находит блок «Список пользователей».
5. Вводит Яндекс ID специалиста.
6. Выбирает роль **«Редактирование»**.
7. Нажимает **«Добавить»**.

Если требуется ограниченный набор функций, владелец может предоставить частичный доступ к инструментам индексирования и поисковых запросов.

**Часть 3. Проверить получение прав**

1. Войдите в Вебмастер под аккаунтом специалиста.
2. Откройте список сайтов.
3. Если сайт ещё отсутствует в списке этого аккаунта, добавьте его под данным Яндекс ID.
4. Откройте «Управление доступом».
5. Проверьте назначенную роль.
6. Убедитесь, что доступны необходимые инструменты.

**Ожидаемый результат:** права предоставлены без повторного самостоятельного подтверждения владения.

**Важно:** добавление сайта под новым Яндекс ID для получения делегированного доступа не означает создание второго сайта или изменение его индексирования.

Не передавайте пароль от аккаунта владельца. Используйте штатное управление правами.

### Д. Выбрать способ самостоятельного подтверждения

Выполняйте только при отсутствии необходимых прав, если вы владеете сайтом или уполномочены подтверждать управление им.

Яндекс Вебмастер поддерживает несколько способов.

| Способ | Когда использовать |
|---|---|
| Метатег | Сайты на Tilda и других конструкторах |
| HTML-файл | Есть доступ к корневому каталогу |
| TXT-запись DNS | Есть доступ к DNS-записям домена |
| Яндекс Тег Менеджер | Уже используется подходящий контейнер |
| Подтверждение через конструктор | Доступна штатная интеграция платформы |

**Рекомендация для GURU:** для Tilda сначала проверить возможность штатного подтверждения. При необходимости использовать метатег.

Не создавайте одновременно несколько новых способов подтверждения без необходимости.

### Е. Получить проверочный метатег

**Часть 1. Открыть подтверждение прав**

1. Откройте https://webmaster.yandex.ru/.
2. Перейдите на страницу «Мои сайты».
3. Найдите нужный сайт.
4. Если рядом есть кнопка **«Подтвердить права»**, нажмите её.
5. Если кнопки нет, нажмите **«⋮» → «Управление доступом»**.
6. Найдите доступные способы подтверждения.

**Часть 2. Выбрать метатег**

1. Выберите **«Метатег на главной странице»**.
2. Если предлагается вкладка **Tilda**, откройте её.
3. Найдите проверочный метатег.
4. Нажмите кнопку копирования.
5. Сохраните полученное значение для следующего действия.

Пример:

```html
<meta name="yandex-verification" content="XXXXXXXXXXXXXX" />
```

`XXXXXXXXXXXXXX` является примером, а не реальным кодом.

**Важно:** используйте исключительно метатег, выданный Вебмастером для конкретного сайта и текущего подтверждения.

Не копируйте коды из других проектов.

### Ж. Разместить метатег в Tilda

**Часть 1. Открыть настройки сайта**

1. Откройте https://tilda.cc/login/.
2. Авторизуйтесь.
3. Выберите нужный проект.
4. Нажмите **«Настройки сайта»**.
5. В левом меню откройте **«Еще»**.
6. Найдите раздел **«Подтверждение прав»**.

**Часть 2. Проверить существующий код**

1. Найдите поле **«Подтверждение домена для Яндекса через мета-тег»**.
2. Посмотрите, заполнено ли оно.
3. Если код уже установлен, не удаляйте его.
4. Сначала установите, используется ли он для действующего подтверждения прав.

**Если необходимые права уже подтверждены:** ничего менять не требуется.

**Если поле пустое и требуется подтверждение:**

1. Вставьте скопированный метатег в формате, предусмотренном полем Tilda.
2. Проверьте, что значение соответствует коду Яндекса.
3. Сохраните настройки.
4. Вернитесь к списку страниц проекта.
5. Нажмите **«Опубликовать все страницы»**.
6. Дождитесь завершения публикации.

**Ожидаемый результат:** метатег размещён на опубликованной главной странице сайта.

Если используется встроенное подключение Tilda через **«Настройки сайта» → «SEO» → «Яндекс Вебмастер» → «Подключить»**, следуйте предлагаемой платформой процедуре и не устанавливайте второй код вручную.

### З. Проверить наличие метатега на сайте

**Часть 1. Открыть опубликованную страницу**

1. Откройте главную страницу сайта.

Например:

`https://k-apple.ru/`

2. Дождитесь полной загрузки.
3. На Mac нажмите `Command + Option + U`.
4. На Windows нажмите `Ctrl + U`.
5. Откроется исходный HTML-код страницы.

**Часть 2. Найти проверочный код**

1. Нажмите `Command + F` или `Ctrl + F`.
2. Введите:

   `yandex-verification`

3. Найдите соответствующий метатег.
4. Посмотрите значение атрибута `content`.
5. Сравните его с кодом из Яндекс Вебмастера.
6. Проверьте, что метатег расположен внутри элемента `head`.

**Правильный результат:** код полностью совпадает с выданным Яндексом.

**Важно:** наличие метатега в редакторе Tilda не подтверждает, что он опубликован. Проверять необходимо именно действующий сайт.

**Если метатег отсутствует:**

1. Вернитесь в настройки Tilda.
2. Проверьте сохранённое значение.
3. Убедитесь, что изменения опубликованы.
4. Повторно откройте исходный код опубликованной страницы.
5. Проверьте метатег ещё раз.

Не добавляйте новый код в общий HEAD, если существующий способ подтверждения уже работает.

### И. Подтвердить права в Яндекс Вебмастере

Выполняйте после успешной проверки опубликованного метатега.

1. Откройте https://webmaster.yandex.ru/.
2. Выберите нужный сайт.
3. Вернитесь на страницу подтверждения прав.
4. Убедитесь, что выбран способ «Метатег на главной странице».
5. Нажмите **«Подтвердить»**.
6. Дождитесь результата проверки.
7. Откройте страницу «Управление доступом».
8. Найдите свой Яндекс ID.
9. Проверьте назначенную роль.

**Ожидаемый результат:** после успешного самостоятельного подтверждения пользователь получает роль «Владелец».

Яндекс указывает, что проверка прав может занимать до 24 часов.

**Если проверка ещё не завершена:** не создавайте новый сайт и не меняйте способ подтверждения без установления причины.

### К. Устранить ошибки подтверждения

| Проблема | Что проверить |
|---|---|
| Метатег не найден | Публикацию Tilda, наличие кода внутри `head` |
| Код не совпадает | Значение `content` и код Вебмастера |
| Неправильный сайт | Домен, HTTPS и наличие `www` |
| Недостаточно прав | Текущий Яндекс ID и назначенную роль |
| Сайт недоступен роботу | HTTP-ответ и настройки безопасности |
| Подтверждение ещё обрабатывается | Статус и результат проверки Яндекса |
| Права ранее были подтверждены, но исчезли | Наличие первоначального способа подтверждения |

**Последовательность исправления:**

1. Откройте страницу подтверждения прав.
2. Прочитайте сообщение об ошибке.
3. Установите, какая проверка не выполнена.
4. Проверьте фактический домен.
5. Проверьте используемый способ подтверждения.
6. Устраните конкретную причину.
7. Если изменялась Tilda, сохраните и опубликуйте изменения.
8. Повторно проверьте результат.
9. Нажмите «Подтвердить», если требуется.

**Важно:** не удаляйте действующий метатег, DNS-записи и другие подтверждения без выяснения их назначения.

### Л. Проверить сохранение прав

Яндекс периодически повторно проверяет право управления сайтом.

**Часть 1. Проверить статус**

1. Откройте Яндекс Вебмастер.
2. Выберите нужный сайт.
3. Перейдите в «Управление доступом».
4. Найдите свой Яндекс ID.
5. Убедитесь, что необходимая роль продолжает действовать.

**Часть 2. Проверить уведомления**

1. Откройте раздел **«Уведомления»**.
2. Найдите сообщения, связанные с подтверждением прав.
3. Убедитесь, что нет уведомления об утрате доступа.

**Часть 3. Сохранить подтверждение**

Если использовался метатег:

1. Убедитесь, что он остаётся в настройках Tilda.
2. Не удаляйте его при других изменениях сайта.
3. После крупных изменений настроек проверьте его наличие на опубликованной странице.

**Ожидаемый результат:** подтверждение прав остаётся действительным.

### М. Проверить готовность к следующим этапам

1. Откройте https://webmaster.yandex.ru/.
2. Выберите нужный сайт.
3. В левом меню раскройте **«Индексирование»**.
4. Проверьте доступность «Страницы в поиске».
5. Откройте «Проверка страницы».
6. Проверьте доступность инструмента.
7. Вернитесь к меню.
8. Раскройте **«Эффективность»**.

**Ожидаемый результат:** пользователь имеет доступ к инструментам, необходимым для контроля индексации и ранжирования.

На этом этапе не изменяйте Sitemap, не запускайте переобход и не создавайте дополнительные настройки.

## 3. Сверка (инструкция)

| Проверка | Правильный результат |
|---|---|
| Сайт | Присутствует в Яндекс Вебмастере |
| Основной адрес | Совпадает с доменом проекта |
| Яндекс ID | Определён |
| Управление доступом | Страница открывается |
| Список пользователей | Доступен |
| Роль пользователя | Соответствует необходимым полномочиям |
| Подтверждение прав | Действует |
| Метатег | Присутствует, если используется |
| Проверочный код | Совпадает с выданным Яндексом |
| Tilda | Изменения опубликованы, если вносились |
| Индексирование | Необходимые инструменты доступны |
| Поисковая статистика | Доступна |
| Дублирование | Отсутствует |
| Существующие данные | Сохранены |

### Итоговый результат

**Готово**

- Сайт найден в Яндекс Вебмастере.
- Необходимые права пользователя подтверждены.
- Назначенная роль соответствует задачам.
- Инструменты индексирования доступны.
- Поисковая статистика доступна.
- Не создано ненужных повторных подтверждений.

**Требует проверки**

- Сайт доступен, но роль пользователя ещё не определена.
- Метатег размещён, но Яндекс не завершил подтверждение.
- Предоставлен частичный доступ, достаточность которого не проверена.
- Есть уведомления о необходимости повторного подтверждения.

**Проблема**

- Права не подтверждены.
- Проверочный код отсутствует или неправильный.
- Пользователь вошёл под другим Яндекс ID.
- Не хватает полномочий.
- Проверочный метатег удалён.
- Сайт недоступен для проверки Яндексом.

**Не требуется**

Повторное подтверждение прав, если необходимые полномочия уже действуют.

### Результат для Яндекс Вебмастера

- Назначение: подтверждение полномочий управления сайтом.
- Приоритет: фундаментальная настройка.
- Механизм: роль пользователя, делегированный доступ или самостоятельное подтверждение.
- Основное ограничение: право просмотра статистики не означает право изменения настроек.
