# 3.2.2. Клик по номеру телефона

## 1. Что сделать (инструкция)

Настроить Яндекс Метрику для регистрации нажатий на телефонные номера сайта и подтвердить, что цель фиксирует именно клики, а не простое наведение курсора.

**Целевое действие:** посетитель нажал на телефонную ссылку, чтобы инициировать звонок.

### Что важно различать

| Действие | Что подтверждает |
|---|---|
| Просмотр номера | Посетитель увидел контакт |
| Наведение курсора | Посетитель навёл указатель на телефон |
| Клик по номеру | Посетитель попытался инициировать звонок |
| Состоявшийся звонок | Телефонный разговор состоялся |
| Квалифицированный звонок | Подтверждено коммерчески значимое обращение |

**Приоритет:** промежуточная конверсия.

Рекомендуемая конфигурация:

- Тип цели: «Клик по номеру телефона».
- Отслеживаемые номера: «Все номера», если дополнительное разделение не требуется.
- «Скрывать часть номера»: выключено.
- Телефонные ссылки: формат `tel:+XXXXXXXXXXX`.
- Для реальных звонков используется отдельная основная цель с данными коллтрекинга.

**Ожидаемый результат:** Метрика регистрирует нажатие на телефонную ссылку и показывает достижение цели в отчёте «Конверсии».

## 2. Где нажать / Как проверить (инструкция)

### А. Проверить существующую цель Яндекс Метрики

Перед созданием новой цели проверьте, нет ли уже подходящей настройки.

1. Откройте https://metrika.yandex.ru/.
2. Войдите через Яндекс ID, имеющий доступ к счётчику сайта.
3. В верхней части интерфейса выберите нужный сайт.
4. Убедитесь, что выбран правильный номер счётчика.
5. В левом меню нажмите «Цели».
6. Найдите «Клик по номеру телефона».
7. Проверьте, нет ли другой автоматически созданной цели с тем же назначением.
8. Если подходящая цель существует, нажмите значок карандаша справа от её названия.
9. Откроется панель «Редактирование цели».
10. Убедитесь, что тип цели: «Клик по номеру телефона».

**Если подходящая цель уже есть:** используйте её. Создавать новую не требуется.

**Если цели нет:** сначала проверьте телефонную ссылку на сайте, затем выполните часть Г этой инструкции.

### Б. Проверить параметр «Скрывать часть номера»

В открытой панели редактирования цели:

1. Найдите переключатели «Все номера» и «Конкретный номер».
2. Определите, какой вариант выбран.
3. Ниже найдите настройку «Скрывать часть номера».
4. Посмотрите положение переключателя.

**Если переключатель включён:**

Метрика может фиксировать наведение курсора на номер телефона на компьютере, а также нажатие.

**Если переключатель выключен:**

Цель предназначена для регистрации нажатий на телефонные ссылки.

Для измерения именно кликов:

5. Нажмите на переключатель «Скрывать часть номера», чтобы выключить его.
6. Убедитесь, что переключатель больше не активен.
7. Нажмите фиолетовую кнопку «Сохранить» внизу панели.

Если переключатель уже выключен, оставьте его без изменений.

**Почему это важно?**

При включённом скрытии номер телефона частично закрывается. На компьютере Яндекс может считать наведение курсора отдельным достижением цели.

В таком режиме показатель отражает не только клики, но и намерение посмотреть полный номер.

Для аналитики переходов к звонку предпочтительнее оставить скрытие выключенным.

### В. Проверить телефонную ссылку в Tilda

**Часть 1. Найти телефон**

1. Откройте https://tilda.cc/login/.
2. Войдите в аккаунт сайта.
3. Выберите нужный проект.
4. Откройте страницу, на которой размещён телефон.
5. Например, это может быть страница «Контакты».
6. Нажмите на название страницы, чтобы открыть редактор.
7. Найдите блок, содержащий номер телефона.

Если телефон размещён в общей шапке или подвале, откройте соответствующую страницу проекта.

**Часть 2. Проверить ссылку текстового номера**

1. Нажмите на текст телефонного номера.
2. Выделите номер.
3. В появившейся панели редактирования нажмите значок ссылки.
4. Найдите поле с адресом ссылки.
5. Прочитайте его значение.

Правильный формат:

`tel:+79169735736`

Это пример из текущего проекта. Для других проектов используйте их фактические телефоны.

Телефон может отображаться как:

`+7 916 973-57-36`

При этом адрес ссылки должен содержать номер без пробелов и скобок.

**Если ссылка правильная:** ничего не меняйте.

**Если ссылка отсутствует или неправильная:**

1. В поле ссылки введите `tel:` и телефон в международном формате.
2. Убедитесь, что указан правильный номер компании.
3. Сохраните ссылку.
4. Сохраните изменения блока.
5. Опубликуйте страницу.

**Если номер находится на кнопке:**

1. Найдите блок с кнопкой.
2. Нажмите «Контент».
3. Найдите поле ссылки для кнопки.
4. Проверьте значение `tel:`.
5. При необходимости исправьте номер.
6. Нажмите «Сохранить и закрыть».
7. Опубликуйте страницу.

### Г. Настроить цель в Метрике, если её ещё нет

1. Откройте https://metrika.yandex.ru/.
2. Выберите счётчик соответствующего сайта.
3. В левом меню нажмите «Цели».
4. Нажмите «Добавить цель».
5. Откроется экран «Новая цель».
6. Найдите категорию «Конверсионные действия».
7. Нажмите «Клик по номеру телефона».
8. В поле «Название цели» введите:

   `Клик по номеру телефона`

9. Ниже найдите варианты отслеживания номеров.

**Вариант 1. Все номера**

Выберите «Все номера», если необходимо учитывать нажатия на все телефонные ссылки сайта.

Это рекомендуемый вариант, когда все номера имеют одинаковое назначение.

**Вариант 2. Конкретный номер**

Выберите «Конкретный номер», если необходимо отдельно учитывать определённый телефон.

1. Найдите поле ввода номера.
2. Введите номер так, как он указан в телефонной ссылке, но без префикса `tel:`.
3. Например: `+79169735736`.
4. Проверьте цифры и знак `+`.

**Важно:** если в ссылке указан `tel:+79169735736`, для конкретного номера в цели нужно указать `+79169735736`.

После выбора номера:

10. Найдите переключатель «Скрывать часть номера».
11. Оставьте его выключенным, если требуется учитывать только клики.
12. Нажмите «Добавить цель».
13. Вернитесь к списку целей.
14. Найдите созданную цель.
15. Зафиксируйте её числовой ID.

**Результат:** цель создана и настроена на регистрацию кликов по нужным телефонам.

Не создавайте одновременно автоматическую и ручную цели с одинаковым назначением без отдельной аналитической необходимости.

### Д. Проверить телефон на опубликованном сайте

1. Откройте опубликованную страницу с номером телефона.
2. Найдите отображаемый номер.
3. Наведите на него указатель мыши.
4. Посмотрите адрес ссылки, который Chrome показывает в нижней части окна.
5. Убедитесь, что адрес начинается с `tel:`.
6. Сравните цифры с действующим номером компании.

**Правильный результат:**

`tel:+79169735736`

Если после `tel:` отсутствует знак `+`, а номер начинается с международного кода, приведите ссылку к единому формату в Tilda.

Это особенно важно, если в Метрике отслеживается «Конкретный номер».

Если выбран вариант «Все номера», Яндекс распознаёт телефонные ссылки по наличию `tel:`.

**Проверка на смартфоне:**

1. Откройте ту же страницу на телефоне.
2. Нажмите номер.
3. Дождитесь появления системного предложения совершить звонок.
4. Сравните отображаемый номер с номером компании.
5. Отмените вызов.

Для проверки клика фактически звонить не требуется.

### Е. Подготовить тестирование цели

**Часть 1. Зафиксировать исходный показатель**

1. Откройте Яндекс Метрику.
2. Выберите нужный счётчик.
3. В левом меню нажмите «Конверсии».
4. Установите период «Сегодня».
5. Найдите цель «Клик по номеру телефона».
6. Запишите текущее количество достижений цели.

Это позволит определить, изменился ли показатель после проверки.

**Часть 2. Открыть отладчик**

1. Откройте новое приватное окно Chrome.
2. На Mac нажмите `Command + Shift + N`.
3. На Windows нажмите `Ctrl + Shift + N`.
4. Не входите в Яндекс Метрику внутри приватного окна.
5. Откройте опубликованную страницу с телефоном.
6. Добавьте к URL параметр `_ym_debug=2`.

Пример:

`https://example.ru/contacts?_ym_debug=2`

7. Дождитесь полной загрузки.
8. В нижней части страницы нажмите значок отладчика Метрики.
9. Откройте вкладку `Counters`.
10. Убедитесь, что указан правильный ID счётчика.
11. Перейдите во вкладку `Events`.

**Ожидаемый результат:** отладчик работает и готов фиксировать взаимодействия с телефонными ссылками.

Если панель отладки не появилась, проверьте блокировщики рекламы и используйте резервный способ через `_ym_debug=1` и консоль браузера.

### Ж. Проверить, что наведение не считается кликом

Этот этап выполняется до контрольного нажатия.

1. На странице найдите телефон.
2. Не нажимайте на него.
3. Наведите курсор на телефон.
4. Удерживайте курсор над номером несколько секунд.
5. Вернитесь к отладчику.
6. Откройте вкладку `Events`.
7. Посмотрите, появилась ли новая запись `Link click`.

**Ожидаемый результат:** от одного наведения курсора событие клика не появляется.

**Если событие появляется:**

1. Откройте Метрику.
2. Перейдите в «Цели».
3. Найдите цель «Клик по номеру телефона».
4. Нажмите значок редактирования.
5. Проверьте переключатель «Скрывать часть номера».
6. Если включён, выключите его.
7. Нажмите «Сохранить».
8. Вернитесь к опубликованному сайту.
9. Откройте страницу заново и повторите проверку наведения.

Если переключатель уже выключен, а событие продолжает возникать без нажатия, необходимо проверить фактический триггер ссылки и дополнительные скрипты сайта.

**Главное:** нельзя считать регистрацию действия «Link click» при наведении доказательством нажатия.

### З. Выполнить один контрольный клик

После успешной проверки наведения:

1. Найдите телефон на опубликованной странице.
2. Нажмите на номер один раз.
3. Если Chrome предложит открыть приложение для звонка, при необходимости отмените запуск.
4. Вернитесь к панели отладчика.
5. Откройте вкладку `Events`.
6. Найдите новую строку `Link click`.
7. Прочитайте адрес после `external url:`.
8. Сравните его с телефонной ссылкой.

Пример ожидаемой записи:

`Link click external url: tel:+79169735736`

9. Убедитесь, что событие отображается под правильным номером счётчика.

**Правильный результат:** одно действие клика зарегистрировано как переход по телефонной ссылке.

**Если видите два разных адреса:**

Например:

`tel:79169735736`

`tel:+79169735736`

Это не обязательно два разных телефонных номера.

Проверьте:

1. Действительно ли выполнялись два отдельных действия.
2. Было ли включено частичное скрытие.
3. Не используется ли на сайте несколько телефонных ссылок с разным форматом.
4. Правильно ли указан конкретный номер в настройках цели.

Если все события относятся к одному телефону, приведите ссылки к единому формату при необходимости.

**Важно:** наличие `Link click` подтверждает регистрацию взаимодействия. Окончательное достижение цели дополнительно проверяется в отчёте «Конверсии».

### И. Если событие клика не появилось

Проверяйте последовательно.

**1. Ссылка**

Откройте редактор Tilda и убедитесь, что номер имеет ссылку, начинающуюся с `tel:`.

**2. Номер**

Если цель настроена на конкретный номер, убедитесь, что он полностью совпадает с номером в ссылке, включая знак `+`.

**3. Счётчик**

Откройте вкладку `Counters` отладчика и сравните ID с выбранным счётчиком Метрики.

**4. Блокировщики**

Проверьте расширения браузера и повторите тест без блокировки Метрики.

**5. Отслеживание ссылок**

Яндекс указывает, что для регистрации телефонных кликов в коде инициализации счётчика должен быть включён параметр:

`trackLinks: true`

Если сайт использует штатную интеграцию Tilda и обычные клики уже отображаются в отладчике, дополнительных изменений не требуется.

Если параметр отсутствует и события не передаются, проверьте код счётчика по официальной инструкции или обратитесь к специалисту, отвечающему за установку Метрики.

**6. Резервная диагностика**

1. Откройте опубликованную страницу с `_ym_debug=1`.
2. На Mac нажмите `Option + Command + J`.
3. На Windows нажмите `Ctrl + Shift + J`.
4. Перейдите во вкладку `Console` браузера.
5. Нажмите на телефонную ссылку.
6. Найдите сообщение вида:

   `Ext link. Counter XXXXXXXX. Url: tel:+XXXXXXXXXXX`

7. Сравните номер счётчика и телефона.

Не устанавливайте второй счётчик для исправления отсутствующего события.

### К. Проверить достижение в Яндекс Метрике

**Через 10-15 минут после контрольного клика:**

1. Откройте https://metrika.yandex.ru/.
2. Выберите нужный счётчик.
3. В левом меню нажмите «Конверсии».
4. Установите период «Сегодня» или период, включающий время теста.
5. Убедитесь, что не выбран ограничивающий сегмент.
6. Найдите цель «Клик по номеру телефона».
7. Посмотрите показатель «Достижения цели».
8. Сравните с количеством, записанным до теста.

**Ожидаемый результат:** зарегистрировано новое достижение проверяемой цели.

Метрика обычно показывает данные через 10-15 минут после события, но иногда обработка занимает больше времени.

**Если достижение отсутствует через 15 минут:**

1. Подождите ещё 15 минут.
2. Обновите отчёт.
3. Проверьте правильность счётчика.
4. Проверьте выбранный период.
5. Убедитесь, что цель существовала до теста.
6. Проверьте отсутствие ограничивающего сегмента.
7. Откройте «Настройки» → «Фильтры».
8. Убедитесь, что тестовый визит не исключён параметром «Не учитывать мои визиты».
9. Сравните результат с записью `Link click` в отладчике.

**Если спустя 30-60 минут достижение отсутствует:**

1. Откройте «Цели».
2. Найдите проверяемую цель.
3. Откройте её редактирование.
4. Проверьте вариант «Все номера» или «Конкретный номер».
5. Если выбран конкретный номер, сравните его с фактической ссылкой `tel:`.
6. Проверьте настройку скрытия.
7. Проверьте `trackLinks`, если событие не передавалось.
8. После исправления ошибки выполните новый допустимый контрольный тест.

Интервал 30-60 минут является практическим временем повторной диагностики, а не гарантированным предельным сроком Яндекса.

**Не создавайте новую цель**, если предыдущая уже существует и данные ещё обрабатываются.

### Л. Проверить отсутствие дублирования

1. Откройте Метрику → «Цели».
2. Найдите ручные и автоматические цели кликов по телефону.
3. Установите, какие номера они отслеживают.
4. Если две цели фиксируют одно и то же действие, определите, действительно ли обе нужны.
5. Для базовой аналитики оставьте одну подходящую цель, сохранив накопленную статистику.
6. Не удаляйте ранее созданные цели без оценки их использования в действующих рекламных кампаниях.

Если проект использует коллтрекинг, цель «Состоявшийся целевой звонок» остаётся отдельной, поскольку измеряет реальный разговор.

Цель на клик не должна подменять её.

### М. Подготовить цель для Яндекс Директа

После успешной проверки:

1. Откройте Метрику → «Цели».
2. Найдите цель «Клик по номеру телефона».
3. Скопируйте числовой ID.
4. Убедитесь, что её достижения появились в отчёте.
5. Убедитесь, что фиксируются именно клики.
6. Проверьте отсутствие ненужных дублей.

**Использование в Директе:**

- Промежуточный сигнал намерения позвонить.
- Не равен полученному обращению.
- Не равен состоявшемуся звонку.
- Не должен получать ту же бизнес-ценность, что квалифицированный звонок, без обоснования.

Если система коллтрекинга уже передаёт реальные звонки, для оптимизации по качественным обращениям предпочтительнее использовать именно их.

## 3. Сверка (инструкция)

### А. Технические критерии

| Проверка | Правильный результат |
|---|---|
| Телефон | Соответствует действующему номеру компании |
| Телефонная ссылка | Начинается с `tel:` |
| Формат номера | Корректный, желательно международный |
| Цель Метрики | Существует без ненужных дублей |
| «Все номера» / «Конкретный номер» | Соответствует задаче |
| «Скрывать часть номера» | Выключено |
| Наведение курсора | Не создаёт событие клика |
| Нажатие | Регистрирует `Link click` |
| ID счётчика | Совпадает с действующим |
| «Конверсии» | Достижение зарегистрировано |
| Состоявшийся звонок | Не приравнивается к клику |

### Б. Итоговый результат

**Готово**

- Телефон оформлен как корректная ссылка.
- Цель Метрики настроена.
- Наведение не учитывается как клик.
- Нажатие зарегистрировано отладчиком.
- Достижение появилось в отчёте «Конверсии».
- Нет необъяснимого двойного учёта.

**Требует проверки**

- `Link click` зафиксирован, но достижение ещё не появилось в отчёте.
- Используется нестандартный телефонный виджет, работа которого пока не подтверждена.

**Проблема**

- Телефонная ссылка неправильная.
- Цель настроена на другой номер.
- Наведение ошибочно учитывается как клик.
- Событие не передаётся.
- После диагностики достижение цели отсутствует.

**Не требуется**

На сайте отсутствует сценарий телефонного обращения и телефонные ссылки не используются.

### В. Подтверждённый практический пример

Для проекта «Коричное яблоко»:

| Параметр | Значение |
|---|---|
| ID счётчика | `105213127` |
| Страница | `https://k-apple.ru/contacts` |
| Телефон | `+7 916 973-57-36` |
| Ссылка | `tel:+79169735736` |
| Название цели | Клик по номеру телефона |
| ID цели | `679332675` |
| Отслеживание | Все номера |
| «Скрывать часть номера» | Выключено |
| Проверка наведения | Отдельного события клика после изменения не выявлено |
| Проверка нажатия | `Link click external url: tel:+79169735736` |

**Подтверждено:** после отключения скрытия номера контрольный клик зафиксирован в отладчике как одно событие.

**Окончательный критерий:** подтвердить достижение цели `679332675` в отчёте «Конверсии», если оно ещё не подтверждено.

### Г. Результат для аналитики

- Назначение: клик по номеру телефона.
- Приоритет: промежуточная конверсия.
- Тип цели: «Клик по номеру телефона».
- Механизм: телефонная ссылка `tel:`.
- Рекомендуемый режим: без частичного скрытия номера.
- Использование: анализ намерения связаться с компанией и вспомогательная оптимизация Яндекс Директа.

**После подтверждения регистрации цели в отчёте она считается полностью настроенной.**
