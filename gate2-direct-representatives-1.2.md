# 1.2. Доступы и представители

## 1. Что сделать (инструкция)

Проверить, кто имеет доступ к рекламному кабинету Яндекс Директа и соответствует ли распределение прав потребностям компании.

**Зачем:** исключить несанкционированный доступ и обеспечить управление рекламой ответственными сотрудниками.

**Ожидаемый результат:** главный представитель определён, имеет полный доступ, дополнительные пользователи подключены только при необходимости.

Если доступы уже настроены правильно, ничего менять не требуется.

## 2. Где нажать / Как проверить (инструкция)

### А. Открыть настройки доступа

1. Перейдите на [https://direct.yandex.ru/](https://direct.yandex.ru/).
2. Авторизуйтесь под рабочим Яндекс ID компании.
3. В левом меню нажмите на логин под кнопкой «Добавить».
4. Выберите «Аккаунт и уведомления».
5. На странице «Настройки» откройте вкладку **«Представители»**.

### Б. Проверить главного представителя

1. Найдите раздел «Главный представитель».
2. Посмотрите указанный логин.
3. Сравните его с основным Яндекс ID компании.
4. Убедитесь, что этот аккаунт находится под контролем компании.

**Пример правильного результата:**

| Параметр | Значение |
|---|---|
| Проект | Коричное яблоко |
| Основной кабинет | `k-apple-ru` |
| Главный представитель | `k-apple-ru` |
| Права | Полный доступ |

Главный представитель может управлять кампаниями, платежами и другими представителями.

Если данные совпадают, ничего менять не нужно. Кнопку «Сменить главного представителя» не используйте.

### В. Проверить дополнительные доступы

1. Найдите раздел «Представители».
2. Проверьте список пользователей.
3. Найдите раздел «Управляющие аккаунты».
4. Проверьте наличие подключённых аккаунтов.
5. Сравните всех пользователей с перечнем сотрудников и подрядчиков, которым компания разрешила доступ.

**Рекомендуемый вариант:** один главный представитель, без дополнительных доступов, если ими никто не пользуется.

Если другому сотруднику действительно необходим доступ:

1. Нажмите «Добавить представителя».
2. Укажите логин его Яндекс ID.
3. Выберите минимально необходимый уровень доступа: «Только чтение» для просмотра или «Полный доступ» для управления рекламой.
4. Заполните обязательные поля формы.
5. Подтвердите добавление.
6. Проверьте появление пользователя в списке и возможность входа под его логином.

Не передавайте сотрудникам пароль от основного Яндекс ID.

### Г. Если обнаружена проблема

**Неизвестный представитель:** установите, кто предоставил доступ и требуется ли он. Если доступ не согласован, главный представитель может отозвать его через меню действий рядом с пользователем → «Удалить».

**Неправильный главный представитель:** уточните принадлежность аккаунта и необходимые полномочия. Не меняйте владельца без согласования.

**Отсутствует необходимый доступ:** добавьте пользователя по инструкции из раздела В и подтвердите его возможность входа.

Изменения для существующей корректной конфигурации сохранять не требуется.

## 3. Сверка (инструкция)

| Проверка | Правильный результат |
|---|---|
| Главный представитель | Совпадает с рабочим аккаунтом компании |
| Полный доступ | Подтверждён |
| Представители | Только согласованные пользователи |
| Управляющие аккаунты | Только согласованные аккаунты |
| Лишние доступы | Отсутствуют |
| Новые доступы | Проверены входом, если создавались |

### Готово

Главный представитель установлен и контролируется компанией. Все дополнительные доступы согласованы либо отсутствуют.

### Требует проверки

Не подтверждена принадлежность основного аккаунта или назначение одного из пользователей.

### Проблема

Обнаружены неизвестные пользователи, неправильный главный представитель или отсутствие необходимых прав.

### Подтверждённый результат «Коричное яблоко»

По скриншоту от 11 ноября 2026 года:

- Главный представитель: `k-apple-ru`.
- Полный доступ: подтверждён интерфейсом.
- Дополнительные представители: отсутствуют.
- Управляющие аккаунты: отсутствуют.

**Итог:** конфигурация доступов корректна при условии, что основной Яндекс ID контролируется компанией. Добавлять пользователей без необходимости не требуется.
